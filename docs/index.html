How it works

One exact theorem, applied automatically

Watanabe, Po, Zaletel and Vishwanath (Phys. Rev. Lett. 117, 096404, 2016) proved that for a nonmagnetic crystal, the space group and the number of electrons per primitive cell decide whether a band insulator is possible at all. symlint implements this for all 230 space groups.

1 · Structure
SrIrO3, Pnma
Any CIF, POSCAR, database entry or generated crystal
→
2 · Count
ν = 556
Electrons per primitive cell, ν = Σ Zi; Pnma needs ν ∈ 8ℕ
→
3 · Verdict
Cannot be an insulator
556 ≡ 4 (mod 8): forced gapless, in about 2 ms
VerdictConditionMeaning
allowedν in the allowed set SGA band insulator is possible (not guaranteed)
odd_fillingν oddCannot be a nonmagnetic band insulator
symmetry_enforcedν even, not in SGForced gapless by nonsymmorphic symmetry: a metal or nodal semimetal

Use cases

Built for machines, usable by anyone

Generative models, ML pipelines and LLM agents handle huge numbers of structures and do not know this theorem. symlint applies it for them.

Database curation

Flag gap labels that symmetry forbids, and shortlist forced gapless materials.

ML guardrail

An exact output constraint for any band gap model, at no training cost.

Generative design

Screen designs before any DFT or GPU time is spent on them.

AI agents

An MCP tool, can_be_insulator, that Claude and other agents can call.

Install

Up and running in a minute

Python 3.10 or newer. The core install is light; heavy ML and MLIP dependencies are optional extras.

git clone https://github.com/Asif-Iqbal-Bhatti/symlint.git
cd symlint
pip install -e .              # core: CLI, Python API, MCP server
pip install -e ".[demo,dev]"  # + marimo app and tests
pytest                        # 16 tests
symlint check my_structure.cif     # any format ASE can read
symlint trace CaZnCu_SG62          # provenance of a stored result
marimo run notebooks/demo.py       # browser app
from symlint import check_file, classify_filling

res = check_file("my_structure.cif")
print(res["verdict"], res["explanation"])

print(classify_filling(nu=316, sg_number=62))   # 'symmetry_enforced'
symlint mcp                              # MCP server over stdio
claude mcp add symlint -- symlint-mcp    # register with Claude Code

More in examples/: screening a folder of structures, constraining a band gap model, connecting an agent.

Scope

Honest limits

  • Valid for nonmagnetic, weakly correlated band theory. Magnetic structures are reported separately, never as violations.
  • A forbidden filling means the crystal cannot be a band insulator. It does not prove a topological material; that needs DFT with spin-orbit coupling and irrep analysis.
  • MLIP stability is a screening estimate and needs DFT confirmation.
